Computational Physics Reference

2D Vector Kinematics & Numerical Integration

In computational kinematics, projectile motion is modeled using 2D Euclidean state vectors for position r⃗ = (x, y) and velocity v⃗ = (vₓ, vᵧ).

// Governing Differential Equations
dr⃗ / dt = v⃗
dv⃗ / dt = a⃗ = g⃗ - k · |v⃗| · v⃗
// Analytical Ideal Vacuum Formulas (k = 0, y₀ = 0)
T = (2 · v₀ · sin θ) / g
H_max = (v₀² · sin² θ) / (2 · g)
R = (v₀² · sin 2θ) / g

Each simulation step advances the state using 4th-Order Runge-Kutta (RK4) vector operations (add, sub, mult, mag, normalize), preserving energy conservation in vacuum while accurately resolving non-linear aerodynamic drag.
